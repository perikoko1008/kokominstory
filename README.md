# 夜話 — 無料の配布版

GitHub Pagesで無料公開するインタラクティブノベルサイトです。`github-pages-release` フォルダのファイルをリポジトリのルートに登録し、Settings → Pages で `Deploy from a branch`、`main`、`/(root)` を選びます。GitHub FreeではPages用リポジトリを公開にする必要があり、サイトのソースと作品データも閲覧可能です。

## 星喰みのアリア

添付された完全プレイログから18場面の選択肢を反映しました。各画面で当日に実際に選ばれた項目には「配信で選択」と表示します。選ばれた選択をたどると記録されたTRUE ENDへ進みます。配信で選ばれなかった選択には、サイト版の短い追加場面を用意し、本筋に合流するか別のIF ENDに進みます。文章はサイト内の定型文から組み立てるため、外部AI、ギフト、追加料金は必要ありません。ギフト介入も物語上の選択肢として無料で体験できます。

## 作品の管理

サイト自体には管理者ログイン画面はありません。作品の追加・削除はGitHub上で `stories.js` を編集します。リポジトリ所有者だけに書き込み権限を与えれば、リスナーはサイトの作品データを変更できません。作品の追加方法は [管理・作品追加ガイド](管理・作品追加ガイド.md) を参照してください。
